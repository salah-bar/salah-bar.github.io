Kebijakan Privasi Salah Bar

Terakhir diperbarui: 1 November 2026

English · Türkçe · العربية · اردو · Bahasa Indonesia · Bahasa Melayu · Français · Русский · Deutsch · Español · فارسی · বাংলা

Singkatnya: Salah Bar tidak punya akun, analitik, iklan, maupun pelacakan, dan pengembang tidak pernah menerima data Anda. Pengaturan, catatan salat, dan data Anda lainnya tetap di perangkat Anda sendiri. Fitur yang Anda pilih hanya mengirim yang diperlukan ke layanan yang menjawab: cuaca dan Masjid terdekat mengirim lokasi Anda, dibulatkan, ke layanan cuaca atau peta; peta memuat gambar area yang ditampilkan; unduhan meminta file yang Anda pilih. Kebijakan tiap aplikasi di bawah mencantumkan semuanya.

Halaman ini mencakup semua aplikasi Salah Bar. Kebijakan lengkap tiap aplikasi, dengan semua yang dilakukannya di perangkat dan setiap layanan yang dapat dihubunginya, ada di sini:

  • Salah Bar untuk Mac, iPhone, iPad, dan Apple Watch
  • Salah Bar untuk Android dan Wear OS (dalam bahasa Inggris)
  • Salah Bar untuk Windows (dalam bahasa Inggris)

Bagian di bawah, tentang masuk dengan Google, berlaku untuk semuanya.

Sinkronisasi dengan Google Drive: apa yang dilakukan Salah Bar dengan data Google Anda

Sinkronisasi dengan Google Drive bersifat opsional dan mati sampai Anda mengetuk Masuk dengan Google di pengaturan sinkronisasi Salah Bar. Fitur ini menjaga data Salah Bar Anda tetap sama di semua perangkat Anda.

Yang diminta Salah Bar dari Google

  • Hanya satu izin: https://www.googleapis.com/auth/drive.appdata, yang ditampilkan Google sebagai “Melihat, membuat, dan menghapus data konfigurasinya sendiri di Google Drive Anda”. Izin ini membuat Salah Bar dapat menyimpan filenya sendiri di folder aplikasi tersembunyi di Drive Anda. Salah Bar tidak dapat melihat, membuka, mengubah, atau menghapus file lain di Drive Anda.
  • Alamat email akun Google Anda, hanya untuk menampilkan akun mana yang sedang masuk.

Salah Bar tidak meminta hal lain: tidak nama, kontak, foto, kalender, atau file Anda yang lain.

Apa yang disimpan, dan di mana

  • Di Google Drive Anda, di folder aplikasi tersembunyi (tidak muncul di daftar file Anda): satu file, Salah Bar sync.json. Untuk tiap perangkat Anda, file ini berisi nama dan platform perangkat serta data Salah Bar Anda: pengaturan dan kota yang disimpan, catatan salat, puasa, kemajuan dan penanda Al-Qur’an, wirid harian, hitungan tasbih, lembar zakat, dan, jika Anda memakai Untuk muslimah, hari-hari uzur. File ini tidak pernah berisi lokasi Anda saat ini atau kata sandi Google Anda.
  • Di tiap perangkat tempat Anda masuk: alamat email akun dan izin masuk (disimpan oleh layanan Google Play di Android, di Keychain di Mac, iPhone, dan iPad, dan dengan perlindungan data Windows untuk akun pengguna Anda di Windows).
  • Tidak di tempat lain. Salah Bar tidak punya server. File dikirim langsung dari perangkat Anda ke Drive Anda sendiri melalui koneksi terenkripsi (HTTPS). Pengembang tidak pernah menerima, melihat, atau menyimpan file itu, alamat email Anda, atau data masuk Anda.

Cara penggunaannya

Hanya untuk menyinkronkan Salah Bar di antara perangkat Anda sendiri: tiap perangkat membaca file, menggabungkan perubahan dari perangkat Anda yang lain, lalu menulis kembali bagiannya sendiri. Salah Bar tidak memakai data Google Anda untuk iklan, tidak menjualnya, tidak memakainya untuk melatih model AI atau pembelajaran mesin, tidak memakainya untuk menilai kelayakan kredit, dan tidak ada orang yang membacanya.

Berbagi

Salah Bar tidak membagikan atau memindahkan data Google Anda kepada siapa pun. Google menyimpannya di akun Anda sendiri, berdasarkan kebijakan privasi Google.

Menghapus data Anda

  • Keluar, di pengaturan sinkronisasi Salah Bar, mengeluarkan data perangkat ini dari file dan menghentikan sinkronisasi di perangkat ini.
  • Hapus Data Saya dari Drive menghapus file dari Drive Anda, beserta data setiap perangkat di dalamnya, dan mencabut akses Salah Bar ke akun Google Anda.
  • Kapan saja, dari luar aplikasi: cabut akses Salah Bar di myaccount.google.com/connections, dan hapus data tersembunyinya di Google Drive versi web → Setelan → Kelola aplikasi → Salah Bar → Opsi → Hapus data aplikasi tersembunyi.
  • Mencopot Salah Bar tidak menghapus file di Drive Anda; gunakan salah satu cara di atas.

Penggunaan Terbatas

Penggunaan oleh Salah Bar, dan pemindahan ke aplikasi lain, atas informasi yang diterima dari Google API akan mematuhi Google API Services User Data Policy, termasuk persyaratan Penggunaan Terbatas (Limited Use).

Anak-anak

Salah Bar tidak punya akun dan tidak meminta informasi pribadi dari siapa pun, termasuk anak-anak. Pengembang tidak menerima data dari siapa pun.

Perubahan

Jika kebijakan ini berubah, versi barunya akan diterbitkan di halaman ini dengan tanggal baru.

Kontak

Pertanyaan tentang privasi: buka issue di github.com/be-liever95/salah-bar/issues.
